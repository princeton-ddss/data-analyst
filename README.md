# Data Analyst

A demo project for the Claude Overload workshop.

## Getting started

1. Run `/setup` in Claude Code to create the uv environment and project directories.
2. Copy `.env.example` to `.env` and fill in any API keys you need (e.g. `CENSUS_API_KEY`).
3. Ask a research question, or use the skills directly: `/ingest`, `/analyze`, `/match`, `/geo`, `/notebook`.

See `CLAUDE.md` for directory layout and analysis conventions.
